## Verna

Small, self-contained tools. Mostly Python, mostly Windows.

| Project | What it does | Download |
|---|---|---|
| **[Price Widget](https://github.com/VernaTeam/verna-price-widget)** | Live Iranian market prices on the desktop, with charts and alerts | [Windows](https://github.com/VernaTeam/verna-price-widget/releases/latest) |
| **[IP Widget](https://github.com/VernaTeam/verna-ip-widget)** | Your public IP, country and ISP, and whether traffic goes through a VPN | [Windows](https://github.com/VernaTeam/verna-ip-widget/releases/latest) |
| **[Duplicate Cleaner](https://github.com/VernaTeam/verna-duplicate-cleaner)** | Finds duplicate files and music, even without names or tags | [Windows](https://github.com/VernaTeam/verna-duplicate-cleaner/releases/latest) |
| **[Verna VPN](https://github.com/VernaTeam/verna-vpn)** | Android VPN on free public configs, each server tested first | [Android](https://github.com/VernaTeam/verna-vpn/releases/latest) |
